## 2. 説明文(ストア掲載用、そのまま貼り付け可)

```
ビジトークは、CEO・海外の同僚・取引先など、相手役やシチュエーション別にキャラクター設定されたAIとリアルタイム音声で練習できるビジネス英会話アプリです。

■ AIとのリアルタイム音声会話
CEOへの報告、海外の同僚との日常会話、取引先との交渉など、全26以上のシーンから選んで、AIを相手に実際に声を出して英語を話す練習ができます。フリートークモードでは、話したいテーマを自分で指定して自由に会話することもできます。

■ 会話ごとのAIコーチによるフィードバック
会話が終わると、文法・語彙・丁寧さをAIがスコアリングし、良かった表現・直すと良い表現を具体的にフィードバックします。

■ リスニング教材・単語帳も聞き放題/学び放題
ビジネス英語のリスニング教材(スクリプト・理解度テスト付き)と、会議・交渉・財務・マーケティングなどテーマ別の単語帳(単語一覧・フラッシュカード・4択テスト)を収録。苦手な単語は自動で復習リストに貯まります。

■ 進捗をマイページで確認
継続日数、週間の会話回数、フルエンシースコアの推移などを一目で確認できます。

【プラン】
・リスニングプラン: リスニング教材が聞き放題
・お試しプラン: AI会話 + リスニング聞き放題
・スタンダードプラン: 全シーンでAI会話 + リスニング聞き放題
・使い放題プラン: AI会話が実質使い放題 + リスニング聞き放題
無料のシーン・教材は登録不要でお試しいただけます。
```

## 4. 年齢制限(レーティング)アンケートの回答目安

**App Store の Age Rating アンケート**:
- 暴力表現・成人向けコンテンツ・ギャンブル等: すべて「なし」
- **ユーザー生成コンテンツ(User-Generated Content)**: 「あり」を推奨(AIとの自由入力会話が該当し得るため)。ただし他の利用者に公開されるものではなく、AIと本人のみが見るコンテンツである旨を備考欄に記載すると安全です。
- **制限のないWebアクセス(Unrestricted Web Access)**: 「なし」(決済・サブスクリプション管理のためのみ特定のURL(Stripe)を開くだけで、汎用ブラウザは提供していません)。

**Google Play のコンテンツレーティング(IARCアンケート)**: 同様に暴力・性的表現等はすべて「なし」、ユーザー生成コンテンツについては上記と同じ考え方で回答してください。

## 5. Appleの「Appのプライバシー」(nutrition label)ドラフト

実際の入力は App Store Connect の「Appのプライバシー」セクションで行います。収集しているデータの目安:

| データの種類 | 収集有無 | 用途 | 本人に紐付くか |
|---|---|---|---|
| メールアドレス | あり | アカウント作成・認証 | あり(アカウントに紐付く) |
| ユーザーコンテンツ(会話内容・保存した単語) | あり | Appの機能提供 | あり |
| 購入履歴 | あり(Stripe経由。App内課金ではない) | Appの機能提供 | あり |
| 使用状況データ(粗い分析) | 必要に応じて(現状は明示的な分析ツール未導入) | - | - |
| 位置情報 | なし | - | - |
| 連絡先・写真・カメラ等 | なし(マイクのみ、リアルタイム音声会話時にのみ使用) | - | - |

マイクの使用は「App の機能」目的として申告し、常時収集ではなくリアルタイム音声会話の実行時のみアクセスする旨を記載してください(`mobile/app.json` の `microphonePermission` 文言と一致させると一貫性があります)。

## 6. Google Play の「データセーフティ」フォームの目安

Appleの表と概ね同じ内容です。「データは暗号化して送信されているか」「ユーザーはデータ削除をリクエストできるか」の質問には、**両方「はい」**と回答できます(Supabase/Stripe/OpenAIはすべてHTTPS経由、かつマイページからアカウントと全データを自己削除可能なため)。
